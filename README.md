# The Governance As Code Playbook

*Adopting FINOS AIGF for Agentic AI in Financial Services*

A practical guide to policy definition, architecture, deterministic orchestration, and observability for agentic AI an FSI organization can actually run in production — built around the FINOS AI Governance Framework (AIGF), CALM, and Fluxnova, and worked through end-to-end against a single KYC document-review use case.

> **First Edition — Draft.** Contents subject to change ahead of first release.

## What this guide covers

Fifteen chapters and a running worked example — an agentic KYC document-review use case — carried from a use-case narrative through taxonomy classification, architecture, CALM specification, Fluxnova process modeling, CI/CD validation, eval-driven testing, production observability, and tokenomics. See the [Introduction](docs/00-introduction.md) for the full shape of the argument, and the [Conclusion](docs/16-conclusion-why-this-matters-more-than-another-framework.md) for a chapter-by-chapter recap.
